# Windows 10 Theme untuk XFCE

## Deskripsi
Theme ini mengubah tampilan XFCE agar mirip dengan Windows 10.

## Isi Package
```
windows-10-theme/
├── xfwm4/              # Window manager theme
├── gtk-2.0/            # GTK2 theme
├── gtk-3.0/            # GTK3 theme
├── metacity-1/         # Metacity theme
├── index.theme        # Theme info
└── README.md          # This file
```

## Warna Dominan
- Primary: #0078D4 (Windows Blue)
- Dark: #1A1A1A
- Light: #F3F3F3
- Accent: #00A4EF

## Instalasi
1. Copy folder ke ~/.themes/
2. Apply melalui XFCE Settings → Appearance → Windows 10

## Kompatibilitas
- XFCE 4.14+
- Xubuntu 20.04+
- Linux Mint XFCE
